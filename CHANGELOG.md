# Changelog

## 0.1.1 — 2026-11-01

- Initial public testing build for WoW: Forever.
- Added compact transient boss warnings.
- Added automatic interruptible boss-cast warnings.
- Added framework for curated MOVE, DEFENSIVE, DISPEL, STACK, SPREAD, and STOP mechanics.
- Added optional role filtering for curated mechanics.
- Added `/fboss debug` capture mode for live boss testing.
- Added `/fboss test`, `/fboss on`, `/fboss off`, `/fboss status`, and `/fboss reset` commands.
- Warning sounds are off by default.
